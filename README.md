# QR Code Component

## Overview

This is my solution to the QR Code Component challenge on Frontend Mentor.

I built this project to practice my HTML and CSS skills.

## Built with

- HTML5
- CSS3
- Flexbox

## What I learned

During this project, I practiced:

- Creating a card layout using HTML.
- Centering elements using Flexbox.
- Working with padding, margin, and border-radius.
- Applying colors, fonts, and box shadows.
- Following a design reference.

## Challenges I faced

I practiced adjusting the card size, spacing, and text alignment to make the result look closer to the original design.
